# PreyLife Documentation

Welcome to PreyLife - a browser-based predator-prey ecosystem simulation demonstrating emergent evolutionary behavior through simple probabilistic rules.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

## System Requirements

- Modern desktop browser (Chrome, Firefox, Safari, Edge)
- WebGL support
- Minimum 4GB RAM recommended for large populations

## Controls Overview

| Key | Action |
|-----|--------|
| Space | Play/Pause simulation |
| R | Reset simulation |
| Click | Spawn creatures at location |
| Scroll | Zoom in/out |
| Drag | Pan the view |

## What You'll See

When you first run PreyLife, you'll see:
- **Blue circles** - Prey creatures seeking food and avoiding predators
- **Red pentagons** - Predator creatures hunting prey
- **Green squares** - Resource food sources

Watch as the population dynamics unfold and creatures evolve specialized survival strategies through natural selection!
