# Classroom Guide

This guide provides activities and lesson plans for using PreyLife in educational settings.

## Overview

PreyLife is suitable for:
- **Grade levels:** High school and college
- **Subjects:** Biology, Ecology, Environmental Science, Computer Science
- **Topics:** Natural selection, population dynamics, predator-prey relationships, evolution

## Learning Objectives

Students will be able to:
1. Explain natural selection using simulation observations
2. Describe predator-prey population dynamics
3. Identify factors affecting ecosystem stability
4. Predict evolutionary outcomes based on environmental conditions
5. Analyze data from population simulations

---

## Lesson 1: Introduction to Predator-Prey Dynamics

**Duration:** 45-60 minutes

**Materials:**
- Computer with PreyLife running
- Student worksheet
- Graph paper or spreadsheet

### Activity

1. **Introduction (10 min)**
   - Define predator, prey, and resources
   - Explain the simulation interface
   - Demonstrate basic controls

2. **Observation Phase (20 min)**
   - Students run simulation for 200 days
   - Record population counts every 25 days
   - Note any extinction events

3. **Analysis (10 min)**
   - Graph prey and predator populations over time
   - Identify population cycles
   - Discuss lag between predator and prey peaks

4. **Discussion (10 min)**
   - Why do predator populations peak after prey?
   - What happens when one species goes extinct?
   - How could the ecosystem be more stable?

### Assessment Questions

1. Describe the relationship between prey and predator populations.
2. What would happen if predators were removed?
3. Why don't predators consume all the prey?

## Lesson 2: Natural Selection in Action

**Duration:** 60-90 minutes

**Materials:**
- PreyLife simulation
- Color observation sheet
- Data collection table

### Activity

1. **Setup (5 min)**
   - Reset simulation with default settings
   - Explain genetic attributes (strength, stealth, etc.)
   - Show how colors represent traits

2. **Baseline Recording (10 min)**
   - Note average traits for prey and predators
   - Describe the color distribution
   - Predict what traits might be favored

3. **Simulation Run (30 min)**
   - Run for 300+ days
   - Record average traits every 50 days
   - Note any visible color changes

4. **Data Analysis (15 min)**
   - Graph trait changes over time
   - Identify which traits increased
   - Calculate rate of change

5. **Discussion (15 min)**
   - Why did certain traits increase?
   - What selection pressure caused these changes?
   - How does this demonstrate natural selection?

### Extension Activity

- Modify predator capture rates
- Predict new evolutionary outcomes
- Test predictions with simulation

## Lesson 3: Ecosystem Stability

**Duration:** 60 minutes

**Materials:**
- PreyLife simulation
- Experiment planning sheet
- Results comparison chart

### Activity

1. **Hypothesis Formation (10 min)**
   - Question: What factors affect ecosystem stability?
   - Students propose hypotheses
   - Plan experiments to test

2. **Controlled Experiments (30 min)**
   - Group 1: Vary initial prey count
   - Group 2: Vary initial predator count
   - Group 3: Vary resource count
   - Run each for 500 days, record extinctions

3. **Data Sharing (10 min)**
   - Groups report findings
   - Compare stability across conditions
   - Identify patterns

4. **Synthesis (10 min)**
   - What conditions create stable ecosystems?
   - What causes extinction cascades?
   - How does this relate to real ecosystems?

## Lesson 4: Genetic Drift and Founder Effects

**Duration:** 45 minutes

**Materials:**
- PreyLife simulation
- Trait recording sheet
- Calculator

### Activity

1. **Introduction (10 min)**
   - Define genetic drift
   - Explain founder effect
   - Discuss importance of population size

2. **Large Population Trial (15 min)**
   - Run with 200 prey, 20 predators
   - Record trait variation at start
   - Note trait variation after 200 days

3. **Small Population Trial (15 min)**
   - Run with 10 prey, 2 predators
   - Record same measurements
   - Note any dramatic trait changes

4. **Comparison (5 min)**
   - Which population showed more trait change?
   - Was trait change due to selection or drift?
   - Why do small populations change faster?

---

## Lesson 5: Speciation and Adaptation

**Duration:** 60-90 minutes

**Materials:**
- PreyLife simulation
- Species conversion tracking sheet
- Evolutionary tree diagram template

### Activity

1. **Introduction (10 min)**
   - Explain species conversion mechanic
   - Discuss real-world speciation
   - Enable species conversion in settings

2. **Long Simulation (40 min)**
   - Run for 500+ days
   - Watch for conversion events
   - Record when and why conversions occur

3. **Analysis (20 min)**
   - What traits led to conversion?
   - How did populations change after conversion?
   - Draw evolutionary tree showing conversions

4. **Discussion (15 min)**
   - How does this relate to real speciation?
   - What environmental pressures cause major transitions?
   - Why is extreme specialization sometimes a dead end?

## Assessment Ideas

### Formative Assessment

- Exit tickets with simulation observations
- Predict-observe-explain activities
- Think-pair-share discussions

### Summative Assessment

**Lab Report:**
Students design and conduct their own experiment using PreyLife, including:
- Hypothesis
- Methods
- Data collection
- Analysis
- Conclusions

**Project Ideas:**
1. Compare PreyLife dynamics to real ecosystem data
2. Create a presentation explaining natural selection using simulation screenshots
3. Design a "stable ecosystem" challenge and solution

## Differentiation

### For Advanced Students

- Modify source code parameters
- Analyze mathematical models
- Compare to Lotka-Volterra predictions

### For Struggling Students

- Provide guided observation worksheets
- Use slower simulation speeds
- Focus on one concept at a time

### For Visual Learners

- Emphasize color changes
- Create time-lapse recordings
- Use population graphs

---

## Discussion Questions

### Ecology

1. How does energy flow through the PreyLife ecosystem?
2. What role do resources play in population dynamics?
3. How does carrying capacity affect populations?

### Evolution

1. What are the requirements for natural selection?
2. How do mutations contribute to evolution?
3. Why doesn't evolution lead to a "perfect" organism?

### Critical Thinking

1. How is PreyLife different from real ecosystems?
2. What simplifications does the simulation make?
3. How could the simulation be more realistic?

## Technical Tips

### Setup

1. Use Chrome browser for best performance
2. Ensure WebGL is enabled
3. Recommend 4GB+ RAM for smooth operation

### Classroom Management

- Have students work in pairs
- Assign specific observation roles
- Use screen sharing for demonstrations

### Troubleshooting

- If simulation slows, reduce population sizes
- Clear browser cache if issues persist
- Refresh page to reset simulation
